# Lucky Ish CBC Smart Learning System | Kenya

**Lucky Ish CBC Smart Learning System** is a Kenyan digital learning support platform designed for learners from **Grade 1 to Grade 12** under the Competency-Based Curriculum (CBC).

🌐 **Live Website:** [https://luckyish15-netizen.github.io](https://luckyish15-netizen.github.io)

## ✨ Key Features
* **CBC Study Resources:** Structured learning support for Kenyan students across primary and secondary levels (Grade 1 – Grade 12).
* **Student Accounts & Practice:** Easy access to revision materials and interactive learning tools.
